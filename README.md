# 🏓 桌球團體賽排點系統

各隊用手機秘密排點，雙方都鎖定後自動同時公布；主辦單位即時登錄比分，所有人手機上即時看到結果。

- **3 點制**（單、雙、雙，先拿 2 點勝）或 **5 點制**（單、雙、單、雙、單，先拿 3 點勝）；每一點三局兩勝或五局三勝
- **排點保密由資料庫把關**：雙方都鎖定前，伺服器不會送出任何一隊的排點，對手用開發者工具也看不到
- 排點規則自動檢查：最少登錄人數（可設定）、單打 1 人、雙打 2 人、同一位選手不能重複出賽
- 隊伍密碼在伺服器驗證，連續輸錯 5 次鎖定 5 分鐘
- 自動產生單循環賽程、手動新增對戰、公布／隱藏對戰
- **積分排名表**：勝一場 2 分、敗一場 1 分；同積分時兩隊看對戰勝負，三隊以上只計算彼此之間的對戰，依序比 場數勝率 → 點數勝率 → 局數勝率 → 分數勝率 → 抽籤，過程中若剩兩隊同分則改看兩隊對戰勝負（主辦在排名表填入抽籤順位）
- 每局記錄實際分數，自動判定每點與整場勝負
- 匯出 Excel、複製 LINE 文字戰報（含積分排名）
- 主辦帳號密碼登入（Supabase Authentication）

純 HTML / JavaScript，不需要安裝或編譯，放上 GitHub Pages 就能用。資料庫、登入與即時同步使用 [Supabase](https://supabase.com)。

> 想先看看？網址後面加上 `?demo` 就是示範模式（資料只存在瀏覽器分頁裡）：主辦密碼 `demo1234`，隊伍密碼為 `1111`～`4444`。

## 設定

### 1. Supabase 專案
可以和其他系統共用同一個 Supabase 專案（本系統的資料表都以 `tl_` 開頭，不會衝突）。

1. **SQL Editor** → **New query** → 貼上 [`supabase/setup.sql`](supabase/setup.sql) 全部內容 → **Run**。（2026-10-08 以前建立的專案，另外執行一次 [`supabase/upgrade-01-draw-rank.sql`](supabase/upgrade-01-draw-rank.sql)）
2. 主辦帳號：**Authentication** → **Users** 需有 `organizer@dsc-table-tennis.app`（或你在 `setup.sql` 第 7 段、`js/config.js` 設定的 email）。
3. [`js/config.js`](js/config.js) 填入 Project URL 與 publishable（anon）key。

### 2. 上線（GitHub Pages）
倉庫 **Settings** → **Pages** → Branch 選 `main`、資料夾 `/ (root)`。

## 比賽流程
1. **主辦管理** → 登入 →「隊伍與選手」新增隊伍或批次匯入（`隊名：隊員1、隊員2…`），系統會為每隊產生 6 位數密碼。
2. 「複製隊伍密碼表」，**分別私下**把密碼傳給各隊隊長。
3. 「設定與匯出」確認賽制、每點局數、最少登錄人數（開始產生對戰後就不能再改賽制）。
4. 「對戰與比分」→「產生單循環賽程」。
5. 各隊在 **各隊排點** 用隊伍密碼登入，管理隊員、為每場對戰排點 →「鎖定送出」。對手尚未鎖定前，可以「解除鎖定」修改。
6. 雙方都鎖定後，排點在 **對戰看板** 同時公布。
7. 主辦「登錄比分」逐局輸入分數；賽後「匯出 Excel」或「複製 LINE 戰報」。
